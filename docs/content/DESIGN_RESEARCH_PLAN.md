# 콘텐츠 실물 디자인·구조·고유 특성 조사 계획 (기획서 보완, 2026-11-10)

> **상태: 계획 문서.** 실물 이미지를 확인한 항목이 하나도 없다. 아래 어떤 항목도 3D 에셋·물성의 최종 확정 근거가 아니다.
> **전제:** 말랑이·슬랑이·크런치 말랑이·왁뿌볼·음식형 스퀴시의 실제 외형·구조·변형·제조 방식·고유 특성을 *모른다*고 가정한다. 이름만으로 모양을 상상하지 않는다.
> **이 문서의 위치:** 저장소에는 "50종 목록" 원본이 없다(`docs/` 전 브랜치 검색 결과 없음). 그래서 50종 원문을 고치지 않고, 원문에 붙일 **추가 요구사항(§1~§4)**과 **조사 대기 목록(§5)**을 별도 문서로 둔다. 원본 목록을 받으면 §5를 50행으로 채운다.
> 기존 기술설계 §6.1~6.2(재질 매트릭스, 10항목 정의)는 **재조사하지 않고 출발점으로만 쓴다**.

## 1. 모든 콘텐츠에 적용하는 조사 필수 기준

**A. 실제 외형** — 전체 실루엣(구/납작/입체 과일/큐브/불규칙) · 가로·세로·높이·두께·볼륨 · 표면(매끈/주름/돌기/패턴/입자) · 색(단색/그라데이션/반투명/내부색) · 마감(무광/유광/끈적임/거칠기) · 손 대비 실제 크기 · 특징적 장식 · 브랜드·모델별 차이.

**B. 내부 구조** — 단일 소재인지 외피/내부 분리인지 · 충전재 · 표면 두께 · 비즈·입자·기포 · 단단한 껍질/깨지는 층 · 파손 전후 구조 변화. **실물에서 확인되지 않은 내부는 확정하지 않고 "미확인"으로 둔다.**

**C. 디자인별 고유 조작** — 모든 제품에 같은 누르기·늘리기를 쓰지 않는다. 아래는 **가설**이며 실물 영상·사진과 대조해야 한다.

| 가설(미검증) | 확인할 것 |
|---|---|
| 고양이 발바닥 말랑이: 패드별 국소 변형 | 패드가 분리 변형되는지, 한 덩어리로 눌리는지 |
| 복숭아 폼: 크게 눌렸다 천천히 복원 | 복원 시간, 형태 유지(소성) 여부 |
| 투명 젤리 큐브: 모서리/면 변형 차이 | 모서리가 실제로 다르게 눌리는지 |
| 비즈 말랑이: 외피 변형 + 내부 입자 이동 | 입자가 실제로 이동·소리 내는지 |
| 치즈형 슬랑이: 길게 늘어나는지 vs 압축형 | 신축성 실물 확인 |
| 얇은 왁뿌볼: 작은 균열이 빠르게 확산 | 껍질 두께와 파손 양상 |
| 두꺼운 왁뿌볼: 큰 파편, 단계적 파손 | 단계 수, 파편 크기 |

**D. 디자인과 소리** — 외형이 달라도 소리가 같을 수 있다. 내부 구조·소재가 다르면 ASMR에 반영되는지 확인하고 아래 5개에 답한다: ① 소리가 나는 곳 ② 압축/복원 각각 소리 유무 ③ 외피 파손음 vs 내부 입자음 ④ 누르기 vs 늘리기 차이 ⑤ 그 디자인만의 소리를 확보할 수 있는가(출처·라이선스 포함, 기존 음원 정책 유지).

## 2. 레퍼런스 규칙

- 콘텐츠마다 **실물 사진 또는 실물 영상 1개 이상**을 목표로 한다. 우선순위: ① 제조사/판매 제품 사진 ② 제품 소개·시연 영상 ③ 구매자 조작 영상 ④ ASMR 영상 ⑤ 다른 게임·3D 자료(구현 참고용만).
- 기록 항목: 정확한 제품명 · 제조사/판매처 · URL · 확인 가능한 외형 특징 · 실제 조작 모습 · **확인 불가 부분**.
- **AI 생성 이미지는 검증 근거로 쓰지 않는다.** 실물 레퍼런스가 없으면 **"외형 미확인"**으로 표시한다.
- 이미지는 **URL만 기록**하고 대량 다운로드·재배포하지 않는다(저작권). 검수 비교용 열람만.
- 사진 한 장으로 보이지 않는 뒷면·내부는 "재현했다"고 주장하지 않는다. 각도별로 확인된 면을 기록한다.

## 3. 변형 vs 독립 콘텐츠

색만 다른 것(빨강/파랑/노랑)은 **독립 콘텐츠가 아니라 스킨**. 아래 중 **하나 이상 실질 차이**가 있을 때만 독립 콘텐츠로 센다: 실루엣 · 내부 구조 · 소재·표면 · 눌리는 방식 · 복원 방식 · 파손 형태 · 고유 ASMR · 특별한 조작. 결과로 "50종"이 "N개 독립 경험 + M개 스킨"으로 재분류될 수 있다(검토 후 사용자 결정).

## 4. 항목별 디자인 분석 형식 (콘텐츠 1개 = 1레코드)

콘텐츠 ID · 이름 · 카테고리 · 실제 제품/창작 변형 · 브랜드·모델 · 레퍼런스 URL · 전체 실루엣 · 표면 질감 · 내부 구조 · 대표 색상 · 고유 디자인 특징 · 고유 물성 · 가능한 제스처 · ASMR 특징 · 3D 제작 방식 · 다른 콘텐츠와 차별점 · **실물 검증 상태**(`미확인` / `제품 정보만` / `사진 확인` / `영상 확인` / `실물 직접 확인`) · 추가 조사 필요 사항.

3D 에셋 명세(실물 확인 뒤에만 작성): 실루엣·기본 메시 / 머티리얼 / 색·텍스처 / 투명·굴절·광택 / 내부 표현 / 변형 가능 영역 / 눌림·늘어남·복원·파손 애니메이션 / 모바일 비용 / **사진 옆에 두고 비교하는 검수 기준**.

## 5. 실물 검증 대기 목록 (현재 알려진 이름만)

**50종 전체 목록이 저장소에 없어서 아래는 부분 목록이다.** 출처는 사용자 지시문 예시와 기술설계 §6.1이다. 상태는 전부 **외형 미확인**. 이미 확인된 사실만 "기존 확인"에 적었다(재조사 금지).

| 카테고리 | 알려진 항목 | 기존 확인(§6.1) | 실물에서 꼭 확인할 것 | 우선순위 |
|---|---|---|---|---|
| 말랑이 | 기본 TPR/실리콘 젤 · 기본 PU 폼 · 고양이 발바닥 · 복숭아 폼 · 투명 젤리 큐브 · 비즈 말랑이 | PU(느린 복원) vs TPR(빠른 복원)은 감쇠 특성이 정반대. TPR인데 슬로우라이징 표기 상품도 있음 | 복원 곡선, 투명도, 내부 비즈, 발바닥 패드 분리 | **1** (MVP 대상, 구현 존재) |
| 음식형 스퀴시 | 감자빵 · 호빵 · 복숭아빵 (PU) · 망고 등 (TPR) · 청사과 · 계란형(경쟁 앱 겹침 목록) | PU 음식은 무광·고거칠·과감쇠로 가정(미확인) | 표면(분말·기공·솜털), 형태 비율, PU/TPR 구분, 장식 | **2** (v1.1, 아트 병목) |
| 왁뿌볼 | 점토 속 · TPR/말랑 속 · 계란형 · 얇은/두꺼운 껍질 변형 | 점토 공 + 왁스 코팅, 한 번 깨면 재사용 불가 [확인]. **같은 이름에 점토(소성)와 TPR(탄성)이 섞임**. 계란형·Savelio·르젠트·굿즈라이프는 제품 자료 미발견 | 껍질 두께, 파편 크기·단계, 속 재질, 균열 양상 | **3** (v1.1 조건부) |
| 슬랑이 | 치즈 · 망고(클리어) · 비누 크런치 · 휘핑크림 · 점토형 | 모두 놓아도 복원되지 않음(가정). 국내 슬랑이가 PVA/TPR/퍼티 중 무엇인지 **미확인**. 비누 크런치는 슬라임+비즈형과 폼 블록형 혼재 | 실제 질감·늘어남, 치즈가 늘어나는지, 비누 크런치 어느 유형인지 | **4** (보류, Mid~Low) |
| 크런치 말랑이 | (알려진 항목 없음) | 없음 | 외피 파손 vs 내부 입자 소리 구조, 반복 사용 가능 여부 | **5** (원본 목록 필요) |

> 사용자 확인이 필요한 질문(조사 전): ① 50종 원본 목록 위치/내용 ② 크런치 말랑이에 포함할 항목 ③ 비누 크런치의 기준 유형 ④ 청사과·계란형을 경쟁 앱 겹침 때문에 제외할지.
