# 키보드 자체 녹음 명세 (미확보 샘플 보완용)

현재 CC0 녹음으로 확보하지 못했거나 확인되지 않은 항목:
- 조약돌·까랑까랑 **스페이스바** 실제 타건(스테빌라이저 포함) — 현재는 "가장 무겁고 긴 일반 키" 대체
- 조약돌 **keyup(복귀음)** — 현재는 분석으로 추정한 약한 타건(실제 복귀음인지 미확인)

## 장비·환경
- 마이크: 소형 진동판 콘덴서 1(키보드 위 15 cm, 사선) + 근접 1(5 cm), 24-bit/48 kHz, 피크 −12 dBFS
- 조용한 방(냉장고·에어컨 OFF), 책상 위 데스크매트, 기기 진동 차단
- 키보드: 조약돌 = 가스켓/폼 보강, 윤활 리니어, 두꺼운 PBT / 까랑까랑 = 알루미늄 하우징, 택타일 또는 리니어, ABS 키캡

## 테이크
- 단일 키 down/up 분리: 키를 누르고 0.5 s 유지 후 떼기 × 키 5종 × 6회 (down·up 각각 30개)
- 세게/보통/살살 3단계 × 각 10회
- 스페이스바: 중앙·좌·우 누름 × 각 8회, 유지 0.5 s 후 떼기
- 동시 입력 참고용: 2·3키 화음 × 10회 (비교용, 샘플로 쓰지 않음)

## 편집
- 개별 타건 분리, onset 0.5 ms 전부터 시작, 꼬리 페이드 8 ms, 노이즈 게이트 −12 dB 이내
- 파일명: `kb_{preset}_{key}_{down|up}_{force}_{take}.wav`
- 기존 스크립트 `app/scripts/kbsamples/build.mjs` 의 입력만 교체하면 스프라이트 재생성 가능
