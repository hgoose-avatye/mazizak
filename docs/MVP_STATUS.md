# MANZIZAK MVP — 현재 상태 (2026-11-18)

> 이 문서는 지금 main(공개 빌드)에 무엇이 들어 있는지와 무엇이 검증되지 않았는지를 적는다. 11/9 v0.1 · v0.2 기록은 맨 아래 "이력"에 그대로 둔다.

## 공개 빌드에 들어 있는 것
- **앱 구조**: 브랜드 스플래시 후 장난감으로 바로 진입, 하단 dock(카테고리 2개: 키캡 / 말랑이), 실제 렌더 썸네일, 설정 시트, 출처와 라이선스 안내, PWA manifest·아이콘. 반응형(줌, 측면 safe area, 낮은 화면) 대응.
- **말랑이 10종**: 슬랑이(S01) · 모닝빵(S02) · 찹쌀떡(S03) · 청사과(W01) · 초콜릿(W02) · 치즈(L01) · 망고(L02) · 휘핑크림(L03) · 비누(C01) · 레인보우(C02).
  - 소재 계열 4가지(탄성 / 점성 / 왁스 / 알갱이). 당겨서 늘리기(슬라임은 늘어난 모양 유지 후 천천히 복원, 탄성체는 되돌아옴).
  - 청사과 껍질·초콜릿 6조각은 누를수록 불규칙하게 깨짐. 초기화 버튼은 왁뿌볼(청사과·초콜릿)에만 표시.
  - 모닝빵·찹쌀떡은 실물 기반 모델.
- **키캡 11종**: 조약돌 · 얼음 · 크림 · 마시멜로 · 민트 · 타자기 + 사용 허락받은 5종(옥구슬 · 복숭아 · 몽돌 · 찌개 · 도자기). 9키+스페이스, 동시 입력, 물리 키보드 입력.
- **사운드**: 실제 녹음 기반(Freesound CC0, YouTube CC BY, 허락받은 프리셋, 소유자 본인 녹음 — 비누 등). 장난감별 무손실 FLAC 청크(해시 파일명)로 필요할 때만 로드, 로딩 칩 표시. 출처: `app/public/sfx/*/CREDITS.md`, [sound/SOURCES_AND_LICENSES.md](sound/SOURCES_AND_LICENSES.md).
- **성능**: 장난감·three.js·오디오 지연 로드. 첫 화면 main 청크 14 KB gzip, three.js 151 KB gzip(장난감을 열 때 로드).

## 자동 검증 (2026-11-18)
- 단위 테스트 230개(229 통과, 1 건너뜀) — 병렬 실행 3회 연속 통과. 타입체크 통과.
- `npm run build` 통과, `check:sfx`(FLAC이 원본 PCM과 샘플 단위로 동일) 통과, `check:dist`(개발용 참조 파일·경로가 빌드에 없음) 통과.

## 아직 사람이 확인해야 하는 것
- **청취**: 레인보우(C02) 부서지는 소리 25개 중 17개는 자동 추출본(아무도 안 들음). 키캡 5종(옥구슬 등)은 파형 수치로 자동 선택, 손 뗄 때 소리 없음. 3라운드 후보(S01 · L02 · L03 · C02 · W02)는 랩에만 있고 미선택. 모닝빵 본인 녹음은 배경 음악 때문에 보류(현재 메모리폼 소리 사용).
- **실기기**: 아이폰·안드로이드 실제 터치 지연, 발열, 첫 터치 소리, 무음 스위치 — 0회. 기획서 킬 기준(키보드 입력→소리 지연)도 미측정.
- **배포**: 호스트 미정, 배포 환경 없음([app/README.md](../app/README.md) "배포 시 캐시·압축"). 서비스워커(오프라인) 없음.
- **키보드 실시간 그림자**: 꺼 둔 상태(WebKit 그림자맵 오류). 다시 켜려면 iOS 실기기 확인 필요.
- **출시 전**: 크레딧 문구·제품명 표현의 법무 확인([research/keyboard-sim/review.md](research/keyboard-sim/review.md) G6).

# MANZIZAK MVP v0.1 — 상태 (2026-11-09)

## 완료
- SPA: 홈(실제 렌더 썸네일 카드) → 말랑이 / 키보드, 설정 시트, PWA manifest·아이콘
- 말랑이(젤리/TPR): 셰이더 변형(2접점), 길게 누를수록 깊게, 끌기, 놓으면 출렁(감쇠 스프링 해석해), 두 손가락 늘리기/오므리기, 색 4종, 초기화, 입장 바운스·유휴 시연
- 키보드: 절차적 조각 키캡+레전드+가공 트레이 케이스, 9키+스페이스, 동시 입력, 누른 위치 기울기, 조약돌/까랑까랑(외형·소리 전환), 물리 키보드
- 사운드: 절차적 합성 효과음(라운드로빈 변주, 강도 연동, 연속 마찰/늘림음), 리미터·보이스 제한, 무음 스위치 존중, 홈 탭에서 오디오 활성화
- 설정: 소리·볼륨·진동(Android)·화질(자동 해상도 하향)·움직임 줄이기·성능 정보(JSON 내보내기)
