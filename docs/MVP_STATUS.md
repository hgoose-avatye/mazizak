# MANZIZAK MVP v0.1 — 상태 (2026-11-09)

## 완료
- SPA: 홈(실제 렌더 썸네일 카드) → 말랑이 / 키보드, 설정 시트, PWA manifest·아이콘
- 말랑이(젤리/TPR): 셰이더 변형(2접점), 길게 누를수록 깊게, 끌기, 놓으면 출렁(감쇠 스프링 해석해), 두 손가락 늘리기/오므리기, 색 4종, 초기화, 입장 바운스·유휴 시연
- 키보드: 절차적 조각 키캡+레전드+가공 트레이 케이스, 9키+스페이스, 동시 입력, 누른 위치 기울기, 조약돌/까랑까랑(외형·소리 전환), 물리 키보드
- 사운드: 절차적 합성 효과음(라운드로빈 변주, 강도 연동, 연속 마찰/늘림음), 리미터·보이스 제한, 무음 스위치 존중, 홈 탭에서 오디오 활성화
- 설정: 소리·볼륨·진동(Android)·화질(자동 해상도 하향)·움직임 줄이기·성능 정보(JSON 내보내기)

## 검증 (실제 실행)
- 단위 테스트 51개 통과, 타입체크·프로덕션 빌드 통과 (main 151KB gzip)
- Chrome 모바일 에뮬레이션(실제 CDP 터치): 화면·조작·사운드 재생 로그·전환 반복·설정 저장, 오류 0
- iOS 시뮬레이터(Safari/WebKit): 홈·말랑이·키보드 렌더 확인 (탭 자동화 불가 → 조작 미검증)
- 독립 QA 에이전트 리포트의 P0/P1 전부 수정 후 재현 스크립트로 재검증

## 미완 / 한계
- 실기기 미검증: 실제 아이폰/안드로이드 터치 지연, 발열, 첫 터치 오디오, 무음 스위치 동작
- 효과음은 합성음이며 사람 귀로 검수되지 않음 (자체 폴리 녹음으로 교체 예정)
