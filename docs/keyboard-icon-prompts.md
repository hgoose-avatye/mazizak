# 키보드 아이콘 이미지 프롬프트 (GPT 이미지 생성용)

키보드 가운데 줄 3개 키에 올릴 아이콘입니다. 키보드 10종 × 3개 = **30장**.
지금은 이모지가 들어가 있는데, 작고 흐릿해서 그림으로 바꿉니다.

## 받으면 할 일

- 파일 형식: **PNG, 배경 투명, 1024×1024**
- 파일 이름: 아래 표의 `파일 이름` 그대로 (예: `pebble-1.png`)
- 넣을 곳: `app/public/keyboard-icons/` 폴더 (없으면 만들어 주세요). 넣어 주시면 키캡에 연결하겠습니다.

## 공통 스타일 (모든 프롬프트 앞에 붙이기)

```
Cute 3D game icon of a single object, soft clay / vinyl toy style, rounded chunky shapes, bold simple silhouette that still reads when shown very small (about 40 pixels), soft studio lighting from the top left, gentle shading, slightly glossy, pastel but saturated colours, centered with generous empty margin around it, no text, no letters, no shadow on the ground, fully transparent background, PNG, 1024x1024.
```

> 팁: 한 번에 한 장씩 요청하면 스타일이 흔들릴 수 있으니, 같은 대화창에서 첫 장이 마음에 들면 "같은 스타일로 다음 것" 식으로 이어서 요청하세요.
