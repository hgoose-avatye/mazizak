# 피젯 직접 녹음 명세 (스톡 대체음 전부 불합격 → 실물 녹음으로 교체)

청취 평가에서 CC0 대체 녹음(스트레스 볼, 반죽, 슬라임, 젤리, 스티로폼, 구슬 등)이 대부분 불합격이었다. 재질이 맞는 소리는 **실제 장난감을 녹음**하는 것이 가장 확실하다.

## 넣는 방법
`app/scripts/fidgets/own/<풀 이름>/` 에 파일을 넣고 `FFMPEG=... node scripts/fidgets/build-clips.mjs` 를 실행하면, 그 풀은 스톡 소스 대신 **내 녹음만** 사용한다(타격 구간 자동 추출 + 품질 게이트). 파일은 풀당 3개 이상 서로 다른 테이크 권장(각 20~40초).

## 풀 이름과 녹음할 동작
| 풀 | 장난감·이벤트 | 녹음할 동작 |
|---|---|---|
| `tpr.tap` | S01 TPR 젤리볼 · tap | 손가락으로 짧게 한 번씩 누르기(0.5초 간격 20회) |
| `tpr.hold` | S01 · hold | 꾹 쥐었다 조금씩 풀기, 천천히 주무르기 |
| `foam.hold` | S02 슬로우 폼 · hold | 깊게 눌러 3~5초 유지 후 천천히 놓기 |
| `foam.tap` | S02 · tap | 짧게 눌렀다 떼기 |
| `mochi.tap` / `mochi.hold` | S03 모찌 | 손끝으로 톡톡 / 반죽처럼 주무르기 |
| `slime.hold` / `slime.stretch` / `slime.fold` | L01 치즈 슬랑이 | 눌러 주무르기 / 양손으로 길게 늘리기 / 접어서 포개기 |
| `gel.hold` / `gel.fold` | L02 망고 슬랑이 | 촉촉하게 눌러 주무르기 / 접기 |
| `cream.hold` / `cream.fold` | L03 휘핑크림 슬랑이 | 폭신하게 뭉개기 / 접기 |
| `soap.crunch` / `soap.hold` | C01 비누 크런치 | 조각을 짧게 부수기 / 계속 누르며 바삭하게 주무르기 |
| `beads.crunch` / `beads.hold` | C02 슈가비즈 | 알갱이 부딪히는 짧은 소리 / 연속으로 자글거리기 |
| `apple.*`, `choco.*` | W01/W02 | 현재 apple77771(CC BY) + 초콜릿 녹음으로 청취 통과. 추가 녹음 시 별도 풀 추가 |

## 녹음 조건
조용한 방(냉장고·에어컨 끔), 마이크를 장난감 5~10cm 앞에 두고 피크 -12 dBFS, 48 kHz WAV(24-bit 권장), 손 장신구·옷 마찰 소음 금지, 한 테이크에 한 동작만. 같은 동작을 강하게/보통/살살 3단계로 각 10회 이상.

## 법적
직접 녹음은 소유자가 저작권자이므로 라이선스 걸림이 없다. 크레딧에는 `Own recording (project owner)`로 기록된다.
