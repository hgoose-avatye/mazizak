# Pixabay 음원 조사 (Agent B)
조사 방식: pixabay.com 직접 접근은 Cloudflare 챌린지(403)로 차단 -> 우회하지 않음. WebFetch/WebSearch 요약 결과만 사용(2026-11-10).
다운로드/분석: 전부 미수행 (ffmpeg도 미설치). 음색 청취 미검증. 모든 항목은 제목/태그 근거의 유사 효과음(실제 장난감 녹음 여부 불명, 합성/녹음 여부 불명).

## 라이선스 (Pixabay Content License 요약, 요약 페이지 기준 - 법적 효력은 전문)
- 무료 사용, 상업 가능, 출처 표기 불필요(권장), 수정 가능
- 금지: 내용 변경 없이(창작적 가공 없이) 단독 판매/배포. 앱에 원본 그대로 번들 시 해석 여지 있음 -> 편집/믹싱 후 사용 권장, 약관 전문 확인 필요
- 상표/로고, 사람 식별 가능 콘텐츠, 오인 유발 사용 제한. 제3자 권리는 사용자 책임
- 다운로드: 상세 페이지에 "Free download" 버튼, MP3. 로그인 필요 여부는 확인 불가(추가 확인 필요)
